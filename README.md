# CMD Compu 💻 Tool

CMD Compu is a learning app designed to help junior IT technicians learn and practice basic computer commands 🤓

## 🚀 Want to Use It?

👉 [CompuApp](https://)

## 📚 Learning Section

There may be a lot to take in at first, but the main purpose of this app is to help junior IT technicians learn basic commands they can use to navigate a computer, search for files, troubleshoot networking issues, find an IP address, check disk usage, and more.

The Learning section is divided into **7 subsections**, each containing a selection of commands that I believe are important and useful to know in an IT support environment.

Each command includes:

* A short description
* Syntax
* Real-world usage examples
* Helpful tips

You can also select the **operating system** you're currently working with, so you can view commands specific to Windows, macOS, Linux, or PowerShell.

## 🎮 Gaming Section

Feeling overwhelmed by all those commands? Take a quick break and play a simple game of **single-player Tic-Tac-Toe**.

You play as **X**, while the computer plays as **O**. It's a small distraction when you need a break from learning. 😄


## 🛠️ Technologies

* **Framework:** Vue
* **Build Tool:** Vite
* **Language:** JavaScript
* **Package Manager:** npm
* **CSS:** Tailwind CSS

## 📦 Installation & Setup

```bash
# Clone the repo
git clone https://github.com/Ajacho/cmd-compu-app.git

# Navigate in
cd Ajacho

# Install dependencies
npm install

# Run locally
npm run dev

```
